## [0.2.0] - 2026-11-10

### Added
- Тёмная тема по умолчанию; для всех тем используется стиль Fusion, поэтому
  кнопки и меню рисуются одинаково на Windows 10/11.
- Точные подписанные URL: реестр запоминает URL каждого манифеста, сегмента и
  ключа из трафика браузера, а загрузчик предпочитает их построенным из
  плейлиста (CDN, подписывающий каждый путь, например phncdn).
- Определение HLS-«семейства»: три сегмента из одного каталога без плейлиста
  образуют карточку; план скачивания строится из записанных URL, init первым.
- YouTube: запрос inner-tube player API из самой страницы (клиент VISIONOS),
  выбор формата до 1080p, видео и звук range-блоками по 8 МБ, мультиплексирование
  FFmpeg без перекодирования.
- Наследование query-параметров манифеста относительными ссылками (подписи и
  токены CDN).
- Диагностический лог (DEBUG, с именами логгеров, ротация 5 МБ × 3). Пишутся
  каждый перехваченный ответ, запросы манифестов и сегментов с кодами ответа,
  cookies, решения по качеству, выбранный вариант, план задачи, команда FFmpeg и
  ошибки. В консоли окна — только INFO.
- Пункт «Открыть лог-файл» и строка с путём лога при запуске.
- Блокировщик рекламы uBlock: `uBlock.crx` лежит рядом с программой,
  распаковывается в `<папка установки>\extensions` (кэш по хешу) и загружается в
  Chromium от Playwright. Chrome и Edge не принимают расширения из командной
  строки, поэтому при наличии `uBlock.crx` программа предлагает скачать Chromium
  и запускает именно его. Файл лежит в репозитории, поэтому установщик
  собирается с блокировщиком и в GitHub Actions.
- Всё, что создаёт программа, живёт в папке установки: `profile` (профиль
  браузера), `browsers` (Chromium), `extensions` (распакованный блокировщик),
  `logs` (логи) — удаление папки программы удаляет и эти данные. Настройки
  остаются в `%APPDATA%`, чтобы пережить переустановку. Если папка установки
  недоступна для записи (`Program Files` без прав администратора), эти папки
  создаются в `%LOCALAPPDATA%\PyDownloader`. Путь к профилю и к данным пишется
  в лог.
- Chromium прежней версии, скачанный в `%LOCALAPPDATA%\PyDownloader\browsers`,
  находится и переиспользуется: повторно он не скачивается.
- Профиль браузера хранится в папке программы (`<app>\profile`), поэтому сессии
  и cookies переживают перезапуск и обновление; профиль прежней версии
  переносится туда один раз.
- Кнопка «Открыть файл» в карточке готового видео запускает скачанный файл в
  плеере по умолчанию; если файла уже нет, открывается папка загрузок.
- Кнопки «Очистить все» и «Очистить скачанные» над списком найденных видео:
  вторая убирает только карточки, чьи файлы лежат на диске. Идёт ли загрузка или
  нет — она не отменяется, файл докачивается.
- Диалог настроек занимает 80% ширины и высоты главного окна и растягивается
  вручную; длинный путь к папке загрузок виден целиком и в подсказке.

### Fixed
- Поток очереди больше не завершается на пустой очереди: он ждёт следующую задачу
  (condition variable), поэтому «Скачать» после запуска действительно качает.
- Кнопка «Скачать» больше не сжимается до нескольких пикселей, когда карточек
  несколько: высота карточки берётся из layout, а не из фиксированного минимума.
- Cookies страницы и CDN объединяются с перехваченными cookies запроса, а не
  заменяют их.
- Плейлист в каталоге уже найденного потока (второй вариант, аудиодорожка) не
  создаёт вторую карточку: его URL запоминается для загрузчика.
- Манифест берётся из уже перехваченного ответа браузера, без повторного запроса:
  CDN с подписью на каждый путь отклоняет второй запрос.
- Если вариант из мастер-плейлиста не получен при поиске, карточка не пропадает:
  загрузчик запросит вариант при скачивании (проверки live/DRM/качества там же).
- План скачивания спускается во вложенный мастер-плейлист (phncdn отдаёт отдельный
  мастер на качество).
- Если CDN подписывает каждый путь, а выбранное качество плеер не запрашивал,
  скачивается лучшее качество, чей URL браузер действительно запросил (в консоли
  видно «Вариант 1080p недоступен, скачиваю 720p»), вместо ошибки HTTP 410.
- Плейлист варианта во вложенном каталоге (`720P_.../master.m3u8`) считается
  частью уже найденного потока и не создаёт вторую карточку.
- Записанные подписанные URL общие для всех строк страницы: загрузка одной
  карточки видит файлы, записанные для другой.
- Папка загрузок спрашивается только при первом запуске: дальше она берётся из
  `settings.json` (и создаётся, если её удалили). Диалог появляется снова, только
  если сохранённый путь недоступен.
- Закрытая страница браузера останавливает сниффер, а не засыпает консоль
  ошибками Playwright.

## [0.1.0] - 2026-11-10

### Added
- Парсер HLS: master/media, `EXT-X-MAP`, `EXT-X-BYTERANGE`, `EXT-X-KEY` (AES-128),
  `EXT-X-MEDIA`, разрешение и bandwidth вариантов.
- Парсер DASH: `BaseURL`-цепочки, несколько `Period`, `SegmentTemplate`
  (`$Number$`, `$Time$`, `$RepresentationID$`, `$Bandwidth$`), `SegmentTimeline`,
  `SegmentList`, `SegmentBase`, `ContentProtection`.
- `QualityFilter` (1080p), `DrmDetector` (Widevine/PlayReady/FairPlay/CommonEncryption),
  классификация кандидатов и реестр источников (дедуп по нормализованному URL,
  объединение Range-запросов MP4, пропуск сегментов найденных манифестов).
- Каркас репозитория: `pyproject.toml`, ruff, mypy, pre-commit, `ci.yml`.
- Перехват трафика через Playwright (Chrome → Edge → Chromium), потоковый разбор
  манифестов, фильтр live → DRM → качество → дедуп, скачивание сегментов
  (до 6 потоков), AES-128, склейка FFmpeg, строгая очередь задач.
- GUI на PySide6: карточки найденных источников с прогрессом внутри карточки,
  консоль с причинами пропуска, настройки, тёмная/светлая/системная тема,
  память размера и положения окна.
- Проверка обновлений через GitHub Releases: кэш, диалог с release notes,
  скачивание установщика, проверка SHA-256, запуск `/SILENT /CLOSEAPPLICATIONS`.
- Сборка: `build.ps1` (версия из тега, PyInstaller, FFmpeg в `bin`, SHA-256),
  `pydownloader.spec`, установщик Inno Setup 6 (`installer/pydownloader.iss`),
  `release.yml` с публикацией установщика и release notes из CHANGELOG.
